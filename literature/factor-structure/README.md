# Factor structure

The **formal model** of equity returns: that a return decomposes into exposures to a small
number of shared forces plus a residual. Theory (single-index, APT, approximate factor
structure), what the factors empirically are, and how much of a return is common.

Distinct from `../market-structure/01-latent-dimensionality/`, which is about the
**methods** for estimating that structure from data (RMT, eigenvalue counting). Model here,
measurement there.
