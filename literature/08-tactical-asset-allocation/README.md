# Tactical asset allocation

Published TAA strategies and the methods underneath them. Most of what is here is not
academic literature: these are practitioner rule-sets, and a recurring feature is that the
rule-set as published is less precise than the backtests quoted for it. Where a strategy's
stated rules are incomplete or proprietary, the note says so, because anything built from
the public description is a reconstruction and should be reported as one.

Allocation methods these strategies borrow, such as the minimum-correlation algorithm
([[varadi-et-al-2012]]), are filed under
`../05-portfolio-construction-and-risk/02-diversification-and-effective-bets/`.
[[prior-sanz-et-al-2026]] is the out-of-sample evidence across 86 such strategies; read it
before any single rule-set.
