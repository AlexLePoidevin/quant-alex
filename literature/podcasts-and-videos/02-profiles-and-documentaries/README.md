# Profiles and documentaries

Third-party films about investors and traders. **Nobody in this folder is making their own
argument** — these are other people's accounts, which is why they are separated from
`../01-lectures-and-interviews/`.

Indexed rather than given one note each. Twelve near-identical stubs saying "not watched,
maker unknown, survivorship bias" would carry no information a single table does not. **A
note gets written when something is actually watched and there is something specific to
say.**
