# Quant Alex

My research repository: notes on the sources I read while learning quantitative finance.

**Browse it as a website: [alexlepoidevin.github.io/quant-alex](https://alexlepoidevin.github.io/quant-alex/)** —
an interactive map of every source and how they connect, with search and backlinks.

It's public so anyone else can learn from it too. The notes summarise published papers,
books and talks; where a paper's PDF can't be shared, its note links to it or gives a
search, so every source is easy to look up. Everything is in
[`literature/`](literature/), organised by subject. Start
with [`literature/README.md`](literature/README.md) for the map.
